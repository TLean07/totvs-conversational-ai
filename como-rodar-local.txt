============================================
  COMO RODAR O PROJETO LOCALMENTE
  TOTVS Conversational Intelligence
============================================

Pre-requisitos:
- JDK 17+
- Python 3.10+
- Node.js 20+
- Acesso ao Oracle Database da FIAP (oracle.fiap.com.br:1521/orcl) com o usuario RM do aluno
- Tabelas criadas uma vez com backend/src/main/resources/db/oracle/schema.sql (SQL Developer ou SQLcl)
- Variaveis de ambiente configuradas a partir do .env.example

Variaveis minimas para ambiente local:
- ORACLE_URL=jdbc:oracle:thin:@//oracle.fiap.com.br:1521/orcl
- ORACLE_USER=RM000000
- ORACLE_PASSWORD=senha-do-oracle
- APP_JWT_SECRET=uma-string-aleatoria-com-32-caracteres-ou-mais
- APP_ADMIN_EMAIL=admin@example.com
- APP_ADMIN_PASSWORD=uma-senha-forte-com-12-caracteres-ou-mais
- APP_COOKIE_SECURE=false
- APP_COOKIE_SAME_SITE=Lax
- AI_SERVICE_TOKEN=outro-token-aleatorio-com-32-caracteres-ou-mais

============================================
  PASSO 1 - MICROSSERVICO DE IA (Python)
============================================

Abra um terminal e execute:

cd ai-service
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
$env:AI_SERVICE_TOKEN="outro-token-aleatorio-com-32-caracteres-ou-mais"
uvicorn app:app --host 0.0.0.0 --port 8000

OBS: Na primeira vez, o modelo BERT sera baixado (~700MB).
     Aguarde ate aparecer "Uvicorn running on http://0.0.0.0:8000"
     Para testar: acesse http://localhost:8000/health no navegador

============================================
  PASSO 2 - BACKEND (Java Spring Boot)
============================================

Abra OUTRO terminal e execute:

cd backend
$env:ORACLE_URL="jdbc:oracle:thin:@//oracle.fiap.com.br:1521/orcl"
$env:ORACLE_USER="RM000000"
$env:ORACLE_PASSWORD="senha-do-oracle"
$env:APP_JWT_SECRET="uma-string-aleatoria-com-32-caracteres-ou-mais"
$env:APP_ADMIN_EMAIL="admin@example.com"
$env:APP_ADMIN_PASSWORD="uma-senha-forte-com-12-caracteres-ou-mais"
$env:APP_COOKIE_SECURE="false"
$env:APP_COOKIE_SAME_SITE="Lax"
$env:AI_SERVICE_TOKEN="outro-token-aleatorio-com-32-caracteres-ou-mais"
.\mvnw.cmd spring-boot:run

Ou com dados de exemplo pre-carregados:
.\mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=demo

OBS: Aguarde ate aparecer "Started ChallengeApplication"
     O backend roda em http://localhost:8080
     Na primeira vez o Maven vai baixar as dependencias (~5min)

============================================
  PASSO 3 - FRONTEND (Next.js)
============================================

Abra OUTRO terminal e execute:

cd frontend
npm install
npm run dev

OBS: O frontend roda em http://localhost:3000
     Acesse no navegador para usar o sistema

============================================
  ORDEM IMPORTANTE
============================================

1. Primeiro: IA (porta 8000)
2. Segundo:  Backend (porta 8080)
3. Terceiro: Frontend (porta 3000)

O backend depende da IA para processar transcricoes.
O frontend depende do backend para buscar dados.
Se a IA nao estiver rodando, as transcricoes ficam com status ERRO.

============================================
  PARA PARAR OS SERVICOS
============================================

Em cada terminal, pressione CTRL+C para parar o servico.
